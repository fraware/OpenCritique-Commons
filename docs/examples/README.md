# Examples and public proof (claim-safe)

Reusable templates and walkthroughs for **method** documentation and
**software** demos. Nothing here unlocks scientific performance claims.

**Non-claims banner**

- Sample fixtures and offline demos are **not** production authenticity.
- Private `runs/` are **not** rights-cleared production fixtures.
- Scorecards stay `NOT AUTHORIZED` (`performance_claims_authorized=false`).
- Do not publish precision/recall or reviewer rankings as authorized results.
- Do not invent production `MANIFEST` readiness or natural decision counts.
