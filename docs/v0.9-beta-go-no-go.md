# v0.9-beta go / no-go checklist

Milestone 4 entry criteria for `v0.9-beta` ([MILESTONES.md](MILESTONES.md)).
This checklist prepares a **decision**; it does **not** unlock scientific
performance claims or cut a beta tag by itself.

`performance_claims_authorized` must remain **false** until §12 gates are met
with natural adjudicated evidence.

## Machine check

Run the executable gate evaluator. **v0.9-beta GO is authorized only when this
script exits 0.** A non-zero exit is NO-GO for beta authenticity surfaces.

```bash
python scripts/check_v09_gates.py
```

The script **discovers evidence artifacts** (it does not hardcode natural=0 /
staffing=false):

| Gate | Evidence path |
|---|---|
| #2 / #3 | `fixtures/*/production/MANIFEST.json` + on-disk `reviews/` |
| #6 | `corpus/matcher-audit/sessions/*.json` (natural session manifests) |
| #7 | `governance/evidence/natural-adjudication-staffing.json` |
| #9 | claims flags across ledger / MANIFESTs / staffing roster |

Absent or blocked evidence fails closed with a detail string pointing at the
artifact path. The evaluator never fabricates evidence and never sets
`performance_claims_authorized=true`. §12 claim surfaces stay locked even after
a GO exit until the claim-authorization matrix in [MILESTONES.md](MILESTONES.md)
is satisfied.

See also: [adapter-authenticity.md](adapter-authenticity.md) workstreams A–F,
[../governance/evidence/README.md](../governance/evidence/README.md).

**Live upstream runners are not authenticity evidence.** Private exports under
`runs/` (Coarse BYOK, OpenReviewer `--from-export` / HF local) deepen the
engineering surface only. They do **not** flip production MANIFESTs to `ready`,
do **not** invent natural denominators, and leave this checklist **NO-GO** until
external A–F evidence lands. Claims stay locked
(`performance_claims_authorized=false`).

## Decision rule

- **GO** for `v0.9-beta` authenticity checklist **only** when
  `scripts/check_v09_gates.py` exits **0** (blocking gates 2, 3, 6, 7 met with
  real evidence).
- **No-go** while any blocking gate remains unmet (`exit code ≠ 0`).
- Engineering release `v0.6.0a0` and process scaffolding do **not** alone
  authorize beta claim surfaces.
- Even after GO, **§12 scientific performance / leaderboard claims remain locked**
  until the claim-authorization matrix is met with adjudicated natural evidence.
