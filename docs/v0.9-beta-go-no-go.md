# v0.9-beta go / no-go checklist

Milestone 4 entry criteria for `v0.9-beta` ([MILESTONES.md](MILESTONES.md)).
This checklist prepares a **decision**; it does **not** unlock scientific
performance claims or cut a beta tag by itself.

`performance_claims_authorized` must remain **false** until §12 gates are met
with natural adjudicated evidence.

## Machine checks (engineering vs scientific)

v0.9 gates are split:

| Script | Role | Exit meaning |
|---|---|---|
| `scripts/check_v09_engineering_gates.py` | Process / scaffolding (informational) | Engineering surface ready; does **not** authorize beta authenticity |
| `scripts/check_v09_scientific_gates.py` | Consequential scientific authenticity (**blocking**) | **v0.9-beta GO only when this exits 0** |
| `scripts/check_v09_gates.py` | Compatibility orchestrator | Runs both; exit status follows the scientific script |

```bash
python scripts/check_v09_engineering_gates.py
python scripts/check_v09_scientific_gates.py
# or: python scripts/check_v09_gates.py
```

The scientific script **discovers evidence artifacts** (it does not hardcode
natural=0 / staffing=false):

| Gate | Evidence path |
|---|---|
| #1 natural rights-cleared cases | `corpus/acquisition-ledger.json` (non-sample imports) + natural calibration seed slots |
| #2 / #3 authentic reviewer outputs | `fixtures/*/production/MANIFEST.json` + on-disk `reviews/` |
| #4 production signing | `trust/scorecard-trust-store.json` (PROD-ROOT / PROD-RELEASE) |
| #5 qualified expert staffing | `governance/evidence/natural-adjudication-staffing.json` |
| #6 matcher audit | `corpus/matcher-audit/sessions/*.json` (natural session manifests) |
| #7 holdout custody | verified `holdout-custody.envelope.json` (≥40 cases **in attested holdout set** + manifest/log-head binding); ledger count alone insufficient |
| #8 independent evaluation | `benchmarks/*/manifest.json` with `evidence_class=expert_natural` and `independent_evaluation=true` |
| #9 claims lock | claims flags across ledger / MANIFESTs / staffing roster |

Absent or blocked evidence fails closed with a detail string pointing at the
artifact path. The evaluator never fabricates evidence and never sets
`performance_claims_authorized=true`. §12 claim surfaces stay locked even after
a GO exit until the claim-authorization matrix in [MILESTONES.md](MILESTONES.md)
is satisfied.

See also: [adapter-authenticity.md](adapter-authenticity.md) workstreams A–F,
[../governance/evidence/README.md](../governance/evidence/README.md).

**Live upstream runners are not authenticity evidence.** Private exports under
`runs/` (Coarse BYOK, OpenReviewer `--from-export` / HF local) deepen the
engineering surface only. They do **not** flip production MANIFESTs to `ready`,
do **not** invent natural denominators, and leave scientific gates **NO-GO** until
external A–F evidence lands. Claims stay locked
(`performance_claims_authorized=false`).

## Decision rule

- **GO** for `v0.9-beta` authenticity checklist **only** when
  `scripts/check_v09_scientific_gates.py` exits **0** (blocking scientific
  gates met with real evidence).
- **No-go** while any blocking scientific gate remains unmet (`exit code ≠ 0`).
- Engineering release `v0.6.0a0` and process scaffolding
  (`check_v09_engineering_gates.py`) do **not** alone authorize beta claim
  surfaces.
- Even after GO, **§12 scientific performance / leaderboard claims remain locked**
  until the claim-authorization matrix is met with adjudicated natural evidence.

- Enabling leaderboards or scientific performance claims
